
# 📚 OKUL PLANLAYICI

Derslerini, sınavlarını ve kitaplarını tek yerde planlayabileceğin kapsamlı bir web uygulaması.

## 🚀 Özellikler

- 👤 Profil Yönetimi (Avatar yükleme)
- 📅 Haftalık Ders Programı
- 📝 Sınav Takvimi
- ⏰ Çalışma Takvimi (17:00-21:00)
- 📚 Kütüphane (Kitap ekleme, test çözme)
- 🏆 Rozet Sistemi
- 👑 Gurur Tablosu (Liderlik)
- ✅ Görev Yönetimi
- 🕐 Saat / Kronometre / Zamanlayıcı
- 🔔 Alarm Sistemi
- 🌙 Koyu / Açık Tema
- 📬 Bildirim Sistemi

## 🛠️ Kullanılan Teknolojiler

- HTML5
- CSS3 (Custom Properties ile tema desteği)
- JavaScript (Vanilla JS)
- Font Awesome (İkonlar)
- LocalStorage (Veri depolama)

## 💻 Kullanım

1. `index.html` dosyasını tarayıcında aç
2. Kayıt ol veya giriş yap
3. Uygulamayı kullanmaya başla!

## 📦 Veri Depolama

Tüm veriler tarayıcının LocalStorage'ında saklanır. Herhangi bir sunucuya ihtiyaç duymaz.

## 🎯 Hedef Kitle

Öğrenciler, ders çalışanlar ve akademik hayatını düzenlemek isteyen herkes.
