# 📚 OKUL PLANLAYICI

Derslerini, sınavlarını ve kitaplarını tek yerde planla!

## 🚀 Özellikler

- 👤 Profil Yönetimi (Avatar yükleme, bilgi düzenleme)
- 📅 Haftalık Ders Programı (Renkli ders kartları)
- 📝 Sınav Takvimi (Otomatik alarm hatırlatıcı)
- ⏰ Çalışma Takvimi (17:00-21:00 arası 5 çalışma + 4 mola)
- 📚 Kütüphane (Kitap ekleme, test çözme, performans takibi)
- 🏆 Rozet Sistemi (7 farklı rozet ile motivasyon)
- 👑 Gurur Tablosu (Genel ve sınıf bazlı liderlik)
- ✅ Görev Yönetimi (Öncelikli görev takibi)
- 🕐 Saat / Kronometre / Zamanlayıcı
- 🔔 Alarm Sistemi (Otomatik ve manuel alarmlar)
- 🌙 Koyu / Açık Tema
- 📬 Bildirim Sistemi
- 💾 LocalStorage ile veri saklama

## 💻 Kullanım

1. `index.html` dosyasını tarayıcında aç
2. Kayıt ol veya giriş yap
3. Uygulamayı kullanmaya başla!

## 📦 Teknolojiler

- HTML5
- CSS3 (Custom Properties ile tema desteği)
- JavaScript (Vanilla JS)
- Font Awesome (İkonlar)
- LocalStorage (Veri depolama)

## 🎯 Hedef Kitle

Öğrenciler, ders çalışanlar ve akademik hayatını düzenlemek isteyen herkes.

## 🔒 Güvenlik

Bu uygulama tamamen istemci taraflıdır (client-side). Tüm veriler tarayıcının LocalStorage'ında saklanır.
